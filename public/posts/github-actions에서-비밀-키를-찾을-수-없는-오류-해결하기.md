# GitHub Actions에서 비밀 키를 찾을 수 없는 오류 해결하기

## 증상 및 오류 메시지
GitHub Actions를 사용하여 CI/CD 파이프라인을 설정할 때, 비밀 키를 찾을 수 없다는 오류 메시지를 자주 접할 수 있습니다. 이 오류는 보통 다음과 같은 메시지로 나타납니다:

```
MY_SECRET is empty
```
GitHub Actions에서 설정되지 않은 secret 참조는 빈 문자열이 됩니다. 위 메시지는 이를 검사하는 사용자 스크립트의 예시입니다. 이로 인해 워크플로우가 중단되거나, 필요한 작업이 수행되지 않아 CI/CD 프로세스에 차질이 생길 수 있습니다.

## 원인 분석
이 오류의 주요 원인은 다음과 같습니다:
1. **비밀 키 설정 누락**: GitHub 리포지토리의 Secrets에 비밀 키가 등록되지 않았을 경우 발생합니다.
2. **잘못된 비밀 키 이름**: 워크플로우 파일에서 비밀 키 이름을 잘못 입력했을 경우에도 이 오류가 발생합니다.
3. **권한 문제**: 비밀 키에 접근할 수 있는 권한이 없을 경우에도 오류가 발생할 수 있습니다.

이러한 원인들을 확인하기 위해, 먼저 GitHub 리포지토리의 설정을 점검해야 합니다.

## 확인 명령어 및 절차
비밀 키가 제대로 설정되어 있는지 확인하기 위해 다음과 같은 절차를 따릅니다:
1. **GitHub 리포지토리로 이동**: 해당 리포지토리의 Settings 탭으로 이동합니다.
2. **Secrets 메뉴 선택**: 왼쪽 사이드바에서 "Secrets and variables"를 클릭한 후, "Actions"를 선택합니다.
3. **비밀 키 확인**: 등록된 비밀 키 목록에서 해당 비밀 키가 존재하는지 확인합니다.

만약 비밀 키가 존재하지 않는다면, 새로운 비밀 키를 추가해야 합니다. 비밀 키의 이름은 대소문자를 구분하므로, 정확히 입력해야 합니다.

## 해결 절차
비밀 키를 찾을 수 없는 오류를 해결하기 위해 다음 단계를 수행합니다:
1. **비밀 키 추가**: 비밀 키가 없다면, 다음과 같이 추가합니다:
   - "New repository secret" 버튼을 클릭합니다.
   - 비밀 키의 이름과 값을 입력한 후 "Add secret" 버튼을 클릭합니다.

2. **워크플로우 파일 수정**: 비밀 키가 올바르게 설정되었는지 확인한 후, 워크플로우 파일에서 비밀 키를 호출하는 부분을 점검합니다. 예를 들어:
   ```yaml
   env:
     MY_SECRET: ${{ secrets.MY_SECRET }}
   ```
   위와 같이 비밀 키 이름이 정확한지 확인합니다.

3. **권한 확인**: 비밀 키에 접근할 수 있는 권한이 있는지 확인합니다. 포크의 pull_request 실행에는 일반적으로 저장소 secret이 전달되지 않으며, 환경 secret은 해당 환경의 접근 규칙을 확인해야 합니다.

## 흔한 실수 및 재발 방지 체크리스트
이 오류를 피하기 위해 다음과 같은 체크리스트를 활용할 수 있습니다:
- [ ] 비밀 키가 GitHub 리포지토리에 등록되어 있는지 확인합니다.
- [ ] 비밀 키의 이름이 정확히 입력되었는지 점검합니다.
- [ ] 비밀 키에 대한 접근 권한이 올바르게 설정되었는지 확인합니다.
- [ ] 비밀 키를 사용하는 모든 워크플로우 파일에서 이름을 일관되게 사용합니다.

이러한 점검 사항을 통해 비밀 키 관련 오류를 예방할 수 있습니다. GitHub Actions를 활용한 CI/CD 파이프라인에서 비밀 키 관리에 신경 써야 합니다. 이러한 오류를 사전에 방지하면, 더 원활한 개발 환경을 유지할 수 있습니다.

## 실무 적용 체크리스트

- GitHub Actions secret not found 해결을 적용하기 전에 현재 운영 환경의 기준값과 예외 상황을 먼저 정리합니다.
- 변경 전후로 확인할 지표를 정하고, 문제가 생겼을 때 되돌릴 수 있는 절차를 문서화합니다.
- 한 번에 모든 서버나 서비스에 적용하기보다 작은 범위에서 검증한 뒤 점진적으로 확대합니다.
- 담당자, 확인 시간, 장애 판단 기준을 명확히 남겨 같은 문제가 반복될 때 빠르게 대응할 수 있게 합니다.
